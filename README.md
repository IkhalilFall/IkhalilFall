## À propos

Développeur full-stack, titulaire d’une **Licence Sciences et Techniques de l’Informatique** de l’Institut Polytechnique de Dakar (IPD). Je conçois des applications web complètes (Angular, Next.js, Node.js, Spring Boot) avec des API REST sécurisées, et je maîtrise l’administration des réseaux et des systèmes (Windows Server, Linux, Docker, Kubernetes).

- 🎓 Projet de fin d’études **E-Mémoire** noté **17/20** (équipe de 4, Product Owner, Scrum)
- 🌐 Basé à Dakar, Sénégal

## Projets à la une

### 🎓 E-Mémoire — gestion des soutenances *(dépôt privé)*
Plateforme web qui centralise tout le cycle de soutenance : sujets, groupes, dépôt des mémoires, jurys, notation et procès-verbaux PDF.
- **Stack :** Angular, Node.js/Express, Prisma, PostgreSQL, Tailwind CSS
- **Points forts :** architecture trois-tiers, authentification JWT et contrôle d’accès par rôle (4 profils), détection automatique des conflits de salle et de jury, 5 sprints Scrum
- **Résultat :** soutenance notée 17/20

### 🏥 [Medicare — prise de rendez-vous médicaux](https://github.com/IkhalilFall/RV_clinique)
Application web pour réserver et gérer des rendez-vous entre patients et médecins.
- **Stack :** Next.js, React, Tailwind CSS, Prisma, MySQL
- **Points forts :** espaces patient et médecin, gestion des disponibilités, confirmation des rendez-vous, suivi du paiement

### 🛒 [API REST E-commerce — Spring Boot](https://github.com/IkhalilFall/ProjetEcomSpringBoot)
API de gestion de produits en couches (contrôleur, service, repository) avec gestion centralisée des erreurs.
- **Stack :** Java 21, Spring Boot, JPA/Hibernate, MySQL

### 🛍️ [Catalogue produits avec panier — Symfony](https://github.com/IkhalilFall/produit_categorie_crud)
Gestion de produits et de catégories (admin) et panier d’achat (utilisateurs) avec rôles `ROLE_USER` / `ROLE_ADMIN` et upload d’images.
- **Stack :** Symfony, Twig, Doctrine

### 📚 [Gestion de cours et d’étudiants — Laravel](https://github.com/IkhalilFall/GESTION-COURS-ETUDIANT)
Application web de gestion des cours et des étudiants.
- **Stack :** Laravel 12, PHP 8.2

### 🌐 Infrastructure réseau et DevOps
- **Windows Server 2025 :** DNS (réplication primaire/secondaire), DHCP en failover, analyse du trafic avec Wireshark
- **Packet Tracer :** VLAN, VTP, DHCP, NAT, routage statique
- **Docker et Kubernetes :** image personnalisée, déploiement, mise à l’échelle, rolling update et rollback
- **CI/CD :** pipeline GitHub Actions avec Docker et Vagrant
