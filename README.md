## Academic Projects

### 🎓 Gestion-Scolaire — School Management System
Group project (4 students) for the Web Application Architectures module. A full school management backend covering authentication, academic records, and document handling.
- **Stack:** Spring Boot, PostgreSQL, Spring Security (JWT), Swagger/OpenAPI
- **Delivered:** role-based access control (student/teacher/admin), full CRUD via DTOs, centralized exception handling, file upload/storage, complete API documentation
- **Status:** all 4 development sprints completed and defended

### ☸️ WSL2 / Docker / Kubernetes Deployment Lab
Graded infrastructure lab (L3 STI3) covering the full path from a WSL2 environment to a containerized application running on Kubernetes.
- **Stack:** WSL2, Docker, Kubernetes (kubectl)
- **Delivered:** custom Docker image, Kubernetes Deployment and Service manifests, live scaling (1 → 3 → 2 replicas), self-healing verification, rolling update with rollback, and a declarative YAML deployment
- **Status:** all exercises completed with full documentation and verification captures

### 🔄 CI/CD Pipeline — Git, Docker & Vagrant
Extension of a Spring Boot REST project (CSC4101) into a full continuous integration and deployment pipeline.
- **Stack:** Git, GitHub Actions, Docker, Docker Compose, Vagrant, VirtualBox
- **Delivered:** a Vagrant-provisioned Ubuntu VM standing in for a production VPS, a self-hosted GitHub Actions runner, an automated build-test-deploy workflow with an ephemeral PostgreSQL service for CI, and rollback on failed deployment
- **Status:** pipeline operational end-to-end

### 🏦 REST API — Bank Account Management (MVC)
CSC4101 module project: a PHP/MySQL REST API rebuilt from a flat script into a proper layered architecture.
- **Stack:** PHP, MySQL (MariaDB)
- **Delivered:** full CRUD rebuilt under a Model-View-Controller pattern, then consolidated into a single REST endpoint with HTTP-verb-based routing
- **Status:** completed

### 🌐 Network Infrastructure — DNS/DHCP Multi-Site (Windows Server 2025)
Systems administration project across two physical hosts simulating a multi-site enterprise network.
- **Stack:** Windows Server 2025, DNS, DHCP
- **Delivered:** primary/secondary DNS replication, DHCP failover with 50/50 load balancing, per-site reservations, DNS over HTTPS, and Wireshark traffic analysis (DORA, zone transfer, ICMP/ARP)
- **Status:** submitted and evaluated

### 📱 Flutter Mobile App — Firebase Authentication
"Fil Rouge" mobile development module project (Dr. Moustapha DER).
- **Stack:** Flutter, Dart, Firebase Authentication
- **Delivered:** structured app (screens / widgets / services layers) with a working authentication flow
- **Status:** completed and functional
